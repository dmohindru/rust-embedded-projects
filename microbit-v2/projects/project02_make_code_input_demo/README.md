## Introduction

This project demo the usage of [MakeCodeInput data structure](../../../embedded-core/src/input_device/make_code_input/mod.rs) that acts as a wrapper for [HC165 driver](../../../embedded-core/src/shift_register/hc165/mod.rs) parallel to serial shift register. Demo was done for [this board](https://shop.elecfreaks.com/products/micro-bit-retro-programming-arcade?pr_prod_strat=e5_desc&pr_rec_id=2e61111b4&pr_rec_pid=7000691277903&pr_ref_pid=6851041755215&pr_seq=uniform)
