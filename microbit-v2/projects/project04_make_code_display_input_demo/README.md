## Introduction

- This project demo the usage of [ST7735 V2 Display Driver](../../../embedded-core/src/display_driver/st7735_driver/v2/mod.rs) and [MakeCodeInput data structure](../../../embedded-core/src/input_device/make_code_input/mod.rs).

- Logic built will be graphics on a display would change on the basis of different button pressed on the board.

- This demo should act as a foundational example for future games developed in this repositories.

Demo was done for [this board](https://shop.elecfreaks.com/products/micro-bit-retro-programming-arcade?pr_prod_strat=e5_desc&pr_rec_id=2e61111b4&pr_rec_pid=7000691277903&pr_ref_pid=6851041755215&pr_seq=uniform)
