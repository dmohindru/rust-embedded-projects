- Display test off: [ADDR: 0x0F , DATA: 0X00]
- Shutdown: [ADDR: 0x0C, DATA: 0X00]
- Scan limit: [ADDR: 0X0B , DATA: 0X07]
- Intensity: [ADDR: 0X0A , DATA: 0X08]
- Decode Mode: [ADDR:0X09 , DATA: 0X00]

### Test scenarios

1. Register Write Framing
   Verify SPI sends:
   [ADDR][DATA]
   Exactly 16 bits per transaction.

2. Initialization Sequence Order
   Make sure:
   Shutdown happens before enabling
   Scan limit is set correctly
   Decode mode is zero

3. Boundary Tests
   Reject intensity > 0x0F
   Reject scan limit > 7
   Reject row index outside 0–7

4. Full Frame Update Test
   If you implement:
   set_row(row: u8, value: u8)
   Test:
   row 0 → sends addr 0x01
   row 7 → sends addr 0x08
   row 8 → error

### Api

For MAX7219?
Very important when:
You toggle CS manually.
Because:

```rust
cs.set_low();
spi.write(&[0x01, 0xFF]).await?;
cs.set_high(); // ⚠ Might be too early!
```

If SPI is still shifting bits,
you might raise CS before transmission completes.

Correct pattern:

```rust
cs.set_low();
spi.write(&[0x01, 0xFF]).await?;
spi.flush().awawit?;
cs.set_high();
```

Now you’re safe.

Summary table
| Method | You Send | You Receive | Typical Use |
| ----------------- | -------- | ---------------- | ------------------- |
| read | Dummy | Real | Sensors |
| write | Real | Ignored | Displays, DAC |
| transfer | Real | Real | Flash, ADC |
| transfer_in_place | Real | Real (overwrite) | Streaming |
| flush | Nothing | Nothing | Wait for completion |

Realistically you only need:

```rust
write()
flush()
```

Everything else is irrelevant for this device.

### spi config code

```rust
use embassy_nrf::spim::{self, Spim};
use embassy_nrf::gpio::{Level, Output, OutputDrive};
use embassy_nrf::peripherals::SPIM0;
use embassy_nrf::config::Config;
use embassy_executor::Spawner;
use embassy_time::Duration;

#[embassy_executor::main]
async fn main(_spawner: Spawner) {
    // Initialize peripherals
    let p = embassy_nrf::init(Default::default());

    // Configure SPI
    let mut config = spim::Config::default();

    // --- SPI MODE 0 ---
    config.mode = spim::Mode {
        polarity: spim::Polarity::IdleLow,      // CPOL = 0
        phase: spim::Phase::CaptureOnFirstTransition, // CPHA = 0
    };

    // --- MSB FIRST ---
    config.bit_order = spim::BitOrder::MsbFirst;

    // --- CLOCK SPEED ---
    config.frequency = spim::Frequency::M2; // 2 MHz (safe choice)

    // SPI pins
    let sck = p.P0_13;
    let mosi = p.P0_15;
    let miso = spim::NoMiso; // MAX7219 doesn't use MISO

    let sck = p.P0_17;   // Edge P13
let mosi = p.P0_13;  // Edge P15
let miso = spim::NoMiso;
let cs = Output::new(p.P0_14, Level::High, OutputDrive::Standard);

    // Create SPI instance
    let mut spi = Spim::new(p.SPIM0, sck, mosi, miso, config);

    // Chip Select (manual GPIO)
    let mut cs = Output::new(p.P0_14, Level::High, OutputDrive::Standard);

    // Example write to MAX7219
    let data = [0x0F, 0x01]; // Display test ON

    cs.set_low();
    spi.write(&data).await.unwrap();
    cs.set_high();

    loop {}
}
```
