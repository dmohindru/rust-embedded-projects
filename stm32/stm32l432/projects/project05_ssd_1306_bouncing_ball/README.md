## Introduction

This example demonstrate the use of SSD 1306 display driver with bouncing ball service

## Features

- Simple demo example demonstrating the driver built for [SSD1306 Display Driver](../../../../embedded-core/src/display_driver/ssd1306_driver/mod.rs)
- One debounced buttons left
- Left button start/pauses the animation.
